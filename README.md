# Golden Jack CLI
An all-in-one blackjack game played directly in your terminal.

This game is built on top of [@golden-jack/engine](https://github.com/golden-jack/engine).
### Installation
Install the package via npm :
```sh
npm install -g @golden-jack/cli
```
Or try it instantly without installing :
```sh
npx @golden-jack/cli
```
### Usage
Launch the game :
```sh
npx @golden-jack/cli
```

Controls :

| Key | Action |
|---|---|
| ← / → | Adjust your bet |
| Enter | Confirm your bet |
| H | Hit |
| S | Stand |
| Space | Next round |
| Escape | Quit the game |
