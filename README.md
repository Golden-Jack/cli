# Golden Jack CLI
An all-in-one blackjack game played directly in your terminal.

This game is built on top of [@golden-jack/engine](https://github.com/golden-jack/engine).
### Installation
Install the package via npm :
```sh
npm install -g @golden-jack/cli
```
### Usage
Launch the game :
```sh
npx @golden-jack/cli
```
Controls : Press `M` to display shortcuts
